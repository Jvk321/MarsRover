# Opcjonalne modele 3D

Domyślnie rover jest proceduralny i nie wymaga plików w tym katalogu.

Opcjonalny `rover_body.glb` zastępuje sam korpus. Koła, zawieszenie i sensory pozostają osobno animowane. Układ: przód +X, góra +Y, prawa strona +Z, 1 jednostka = 1 kafel. Szczegóły wymiarów i zmiany ścieżki na GLTF opisano w `ROVER_3D.md` w katalogu projektu.
